## AIM

To create a personal portfolio website using HTML to display personal information, technical skills, projects, education, and contact details.

## ALGORITHM

**STEP 1:** Create an HTML file named `index.html`.

**STEP 2:** Add the basic HTML structure using HTML tags.

**STEP 3:** Include a navigation bar with links to different sections.

**STEP 4:** Create sections for About Me, Skills, Projects, Education, and Contact.

**STEP 5:** Add personal information and profile details.

**STEP 6:** Add technical skills using an unordered list.

**STEP 7:** Display project details using headings and paragraphs.

**STEP 8:** Add educational qualifications and certifications.

**STEP 9:** Add contact information and social media links.

**STEP 10:** Insert a profile image using the HTML image tag.

**STEP 11:** Open the HTML file in a web browser.

**STEP 12:** Check the navigation links and verify the webpage.

**STEP 13:** Correct errors if any are found.

**STEP 14:** Upload the portfolio project to GitHub.
